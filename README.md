# 考场规则

> 规则第一条：本考场没有监考老师。规则最后一条：本场考试只有一名考生。

**题材**：悬疑 · 校园 · 超自然　**作者**：灯下人　**4 章 · 13,218 字**

高考前夜，全校收到一本《考场规则手册》，第一条写着“本考场没有监考老师”。违反规则的学生会从所有人的记忆里消失。复读生林昭发现同桌陈默已经被抹掉，只有她还记得他。她必须在黎明前找到手册最后一页的隐藏规则，才能救回陈默。随着一条条规则被触发，校园越来越空，记忆越来越薄。她最终发现最后一条规则是“本场考试只有一名考生”——烧掉手册走出教室，全校一千二百人重新出现在操场上，只有她的座位永远空着。
